# 知识花园界面

本文档记录 Aya's Knowledge Garden 的界面结构及内容映射，设计参考仓库根目录的 `设计样图.png`。

## 页面范围

- 知识花园首页高还原设计样图，承担站点介绍、知识领域概览和内容发现。
- 内容阅读页共享首页的字体、配色、卡片、侧栏与装饰语言，但保留适合长文阅读的正文宽度和信息层级。
- 界面仅呈现有真实目标的入口，不创建空白占位页或无效按钮。

## 首页内容

- 主区域显示欢迎信息和真实知识领域。
- `content` 下第一层目录对应知识领域，其下目录对应可继续嵌套的主题。
- 每个知识领域卡片展示直接子主题；笔记数量递归统计其下所有非 `index.md` 的 Markdown 笔记。
- 任意目录中的 `index.md` 是该层级首页，不计入笔记数量。
- 左侧栏包含站点品牌、搜索、首页入口、真实内容树和明暗主题切换。
- 右侧栏包含知识图谱、首页目录和最近更新笔记。

## 发布范围与字数统计

- Git `HEAD` 是站点内容的权威来源，构建时只发布已由 Git 追踪的 Markdown；未追踪的新笔记不会进入领域卡片、Explorer、最近笔记、搜索或知识图谱。
- 每个知识领域卡片显示已发布笔记数量、今日正文字符净变化和当前正文总字符数。
- 今日变化以 Asia/Shanghai 自然日为界，比较今日零点前最后一次提交与当前 `HEAD`；新增显示正数，删减显示负数，无变化显示零。
- 字符统计排除 Frontmatter、Markdown 标记和空白，保留正文、行内代码与代码块中的非空白字符；各层级 `index.md` 不参与统计。
- GitHub Actions 必须使用完整 Git 历史；当前部署工作流通过 `fetch-depth: 0` 满足该要求。

## 视觉语言

- 浅色主题以奶白背景、深靛紫文字、淡紫交互色和樱花粉点缀为主。
- 深色主题沿用相同层级与色彩关系，单独提供低亮度背景和柔和高亮，不使用简单反色。
- 装饰使用 CSS 与内联 SVG 绘制，不把设计样图或其裁切区域作为页面背景。
- 卡片使用细边框、低对比阴影和较大的圆角，避免装饰影响正文可读性。

## 响应式布局

- 桌面端采用左栏、正文、右栏三列布局。
- 平板端正文优先，导航可展开，右侧信息卡移动到正文下方。
- 移动端采用单列布局和抽屉导航；大型装饰减少或隐藏。

## 验收

- 构建过程无 TypeScript、Sass 或 Quartz 配置错误。
- 首页分类、链接和数量来自已发布 Markdown 内容。
- 浅色与深色主题均保持文字可读、控件可辨识。
- 桌面、平板和移动端不存在横向溢出或内容遮挡。

## 第一轮界面反馈

- 左侧站点标题使用更克制的字号，避免抢占导航区域的视觉重心。
- Explorer 的当前条目使用知识花园主题的紫色底色与强调色。
- 桌面端 Explorer 折叠时隐藏栏目并保留标题；平板与移动端使用可开合的侧滑导航。
- 右侧目录折叠时只隐藏目录条目，目录标题和折叠按钮始终可见。
