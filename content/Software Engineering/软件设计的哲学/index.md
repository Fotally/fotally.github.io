# 复杂性

复杂性是指与软件系统有关的，使人难以理解和修改系统的所有因素。

通常有三种表现：

- **变更放大**：需要在很多不同的地方修改同一份代码。
- **认知负担**：在修改这个模块时，需要掌握多少额外的知识。
- **不知道未知**：不知道必须修改哪些代码才能完成任务。

复杂性的原因：

- **依赖关系**：依赖关系会出现在软件系统的方方面面，本身不是复杂性膨胀的根源，但是如果依赖关系混乱，会出现**变更放大**和**认知负担**两种复杂性的表现。
